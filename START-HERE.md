# Фестиваль мороженого — регистрация гостей (START HERE)

**Что это.** Заказ: инструмент сбора контактов посетителей фестиваля мороженого
(Центральный рынок) для последующих email/SMS-рассылок и CRM. Реализован как
**мобильный лендинг** (не Telegram-бот — сознательно, ради конверсии на потоке).

**Клиент.** Контакт — **Ксения** (координатор). Бюджет решает **руководитель**.
До нас дошло через посредника (Дмитрий → руководитель Ксении).

## Файлы проекта
| Файл | Что |
|---|---|
| `index.html` | сам лендинг (форма Имя*/Телефон*/email, 2 согласия, успех, панель «Организатору» с экспортом CSV) |
| `qr-festival.png` | QR на печать (тёмный #3A2530, коррекция H). Копия на Desktop |
| `plakat-a6.html` | готовый мини-плакат A6 на стойку, QR внутри → Ctrl+P. Копия на Desktop |
| `tools/gsheet-endpoint.gs` | код Apps Script для боевой общей таблицы (ещё не задеплоен) |
| `messages.md` | все отправленные клиенту сообщения (для контекста/переписки) |
| `STATUS.md` | оперативное состояние — **читать первым при возобновлении** |

## Возобновление сессии
1. Прочитай `STATUS.md` (что сделано / чего ждём / что делать по «да»).
2. Если Ксения ответила согласием — переходи к разделу «Боевой запуск» в STATUS.md.

Полный контекст остаётся в project-memory: `festival-morozhenoe.md`.
